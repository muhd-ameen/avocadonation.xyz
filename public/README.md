# Hero video

Drop your holographic character video here as:

- `character.webm` (preferred — smaller, supports alpha/transparency)
- `character.mp4` (fallback)

The Hero references `/character.webm` then `/character.mp4`. No styling is needed
on the file itself — the video sits with no border or container, and its black
background blends into the page background (#050505). For the cleanest blend,
export the video on a solid #050505 background or with a transparent (alpha)
channel in WebM.

Until a file is present, the hero's right side simply renders as black, which
matches the intended look.
